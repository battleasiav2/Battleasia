SINGLE DOMAIN UPLOAD — nixbazar.com
====================================

Run build first:
  powershell -ExecutionPolicy Bypass -File hosting/scripts/build-for-nixbazar.ps1

Then upload EVERYTHING from this folder to public_html/

Structure after upload:
  public_html/
    index.html          Player site (/)
    assets/             Player assets
    store/              Coin shop (/store/)
    admin/              Admin panel (/admin/)
    .htaccess           SPA routing

API (separate Node.js app on server):
  Upload hosting/api/ folder
  Set .env from .env.example
  npm install --omit=dev
  node dist/index.js  (port 5050)
  Enable /api/ proxy in .htaccess (uncomment lines) OR Webuzo reverse proxy

Live URLs (one domain only):
  https://nixbazar.com/
  https://nixbazar.com/store/user/shop
  https://nixbazar.com/admin/
  https://nixbazar.com/api/health

See hosting/SETUP-NIXBAZAR.md for full steps.
